Data
=======

The `data/` directory contains all datasets, intermediate files, and outputs generated by the models.
This structured organization ensures reproducibility and clarity throughout the project.
The directories and files listed below are managed by Git unless otherwise noted.

* **full\_dataset.csv**: The complete, unfiltered dataset. It includes columns for `id`, `smiles`, `cmpdname`, `mw`, `mf`, `polararea`, and `complexity`.
* **original\_dataset.csv**: The original raw dataset containing extensive molecular information, such as `id`, `cmpdname`, `isosmiles`, `canonicalsmiles`, and various stereochemistry and physical properties.
* **reduced\_dataset.csv**: A smaller subset of the data, likely used for testing or specific model runs.
* **polarizability\_data.csv**: Processed data for monomer training, containing molecular features and polarizability values.
* **polarizability\_data\_copoly.csv**: Processed data for copolymer training.
* **ga\_output/**: The output directory for the genetic algorithm, storing the final population and any related analysis.
* **generative\_data/**: Stores datasets specifically prepared for the GPT-based generative model.
* **generative\_output/**: The final output of the generative process, including the generated molecules and their properties.
* **gnn\_output/**: Stores the trained GNN model for monomers, along with training statistics and performance metrics.
* **gnn\_output\_copoly/**: Stores the trained GNN model for copolymers and its corresponding outputs.

## Git-Ignored Directories

The following directories are intentionally ignored by Git as they contain large, generated, or temporary files:

* **molecules/**: Holds the output data from DFTB+ simulations, which is used to derive molecular properties.
* **training\_input\_data/**: Stores pre-processed monomer graphs in PyTorch Geometric format (`.pt` files) for the GNN model.
* **training\_input\_data\_copoly/**: Stores pre-processed copolymer graphs for the GNN.
* **validation\_data/**: The set of monomer graphs held out for model validation and prediction.
* **validation\_data\_copoly/**: The validation set of copolymer graphs.
* **xyz\_files/**: Contains XYZ files for the molecules, typically used for molecular geometry visualization.
* **generative\_model/**: Contains the trained GPT generative model.
